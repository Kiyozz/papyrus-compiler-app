The SKSE scripts left in Data\Scripts\Source, where the SKSE archive puts them, no longer raise the legacy source folder warning. The script extender check now also finds the loader and the SKSE scripts when they only live in Mod Organizer 2's virtual file system (mods, Root Builder), and its warning tells MO2 users to install SKSE as a mod and launch PCA from MO2.
